Tech Stack: Swift, SwiftUi, Swift Concurrency (async/await)
Architecture: MVVM + Dependency Injection (Protocol PersistenceStore)

The generator populates the database with 100 ModelA and 100,000 ModelB objects
with randomized values and relationships in a single asynchronous background task.
